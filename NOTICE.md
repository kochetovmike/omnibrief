# Sources & licences

Omnibrief publishes automated digests built from openly licensed vulnerability data. Sources are
credited for the **data**; the summaries are Omnibrief's own and are not endorsed by any source.

## Data sources

- **CISA Known Exploited Vulnerabilities (KEV) catalog** — U.S. Cybersecurity and Infrastructure
  Security Agency (CISA). Distributed under the Creative Commons 0 1.0 (CC0) public domain dedication.
  Used to flag actively exploited vulnerabilities. Use of this data does not imply endorsement by CISA.
  <https://www.cisa.gov/known-exploited-vulnerabilities-catalog>

- **National Vulnerability Database (NVD)** — NIST. This product uses the NVD API but is not endorsed or certified by the NVD.
  Summaries on this site are modified content produced by Omnibrief and are not attributable to the NVD.
  <https://nvd.nist.gov/>

- **GitHub Advisory Database** — © GitHub, Inc. and contributors, licensed under the Creative Commons
  Attribution 4.0 International licence (CC-BY 4.0, https://creativecommons.org/licenses/by/4.0/).
  Advisory content has been modified: it is filtered, merged with other sources and summarised.
  <https://github.com/advisories>

- **EPSS** — Exploit Prediction Scoring System, FIRST. See EPSS at https://www.first.org/epss

## Disclaimer

Summaries are machine-generated by Omnibrief from the sources above and may contain errors.
They are not endorsed by any source. Always check the linked original.

Links inside digests point only to references contained in the source records, or to this site.
